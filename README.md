🦖 Dino Suika: Игра слияния динозавров с физикой!

«Dino Suika» — это увлекательная браузерная игра-головоломка, вдохновлённая классической механикой объединения фруктов (Suika), но с уникальным поворотом: вместо фруктов здесь падают милые пиксельные динозавры!
Используйте законы физики, чтобы объединять одинаковых динозавров. Будьте осторожны: если коробка переполнится, игра закончится."

🚀 Демо-версия доступна прямо сейчас!

Игра работает полностью в браузере без установки:

➡️ Играть онлайн: https://lokkie7.github.io/Dino-suika-game/

Проект написан на чистом JavaScript и HTML/CSS без фреймворков.

Если вы хотите запустить игру у себя на компьютере, выполните следующие шаги:

Скачайте исходники из репозитория.
Откройте папку проекта в любом современном браузере.
Для Chrome/Edge откройте консоль (F12) и включите флаг allow-file-access-from-files в разделе chrome://flags, иначе могут быть проблемы с загрузкой файлов.
Загрузите index.html.

Примечание: Это статическая веб-игра, не требующая серверной части или компиляции.

🎨 Арт и ресурсы
Все изображения динозавров созданы ai в стиле pixel art. Вы можете найти их в папке /images. Можете свободно использовать их.
